This plugin cannot protect a hidden volume the way VeraCrypt on Windows does. Mount an outer volume that contains a hidden one read-only, or writing to it can destroy the hidden volume.
Everything that walks this share (backups, indexers, activity loggers) then also walks into the decrypted data. The mount is not visible through per-disk paths.

If it fails

The same dialog stays open and shows one of these:
Could not unlock. Wrong password, PIM or keyfile.
Not mounted: the volume was not closed cleanly. Mount it in VeraCrypt on Windows and run a disk check (chkdsk), then try again. Nothing was changed.
Refused: the volume file is open on PC-OFFICE. Dismount it there first. Mounting it in two places at once damages it.

VeraCrypt Mount
Adds a "VeraCrypt Volumes" section below the disks on Main. While this is "No", the plugin adds nothing at all to the Main page.
With "Yes", the password dialog refuses to open over plain HTTP. Unlocking over SSH with vcmount always works.
